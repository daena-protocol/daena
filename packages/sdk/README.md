# @daena/sdk

The publisher and agent SDK for the Daena Protocol.

Use this package to:

- **Publish.** Author Daena documents in code, sign them with your publisher identity, and serve them.
- **Consume.** From an agent, call `QUERY`, `ACT`, `SUBSCRIBE`, and `VERIFY` against any Daena endpoint.

## Status

Pre-alpha. Interfaces will change as the spec evolves toward v1.
