# @daena/renderer

Render Daena documents to human-readable views.

The renderer takes a Daena document and produces a *human view* — by default HTML, but pluggable for voice, plain text, and other modalities. Render hints embedded in the document guide layout; they never affect semantics.

This package is what guarantees the Daena Protocol does not abandon the human web — humans still get a readable interface, but it is *derived* from the canonical agent layer rather than hand-coded by every publisher.
